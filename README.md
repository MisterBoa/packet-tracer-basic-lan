# Basic LAN Configuration

## Project Overview

This project demonstrates a basic Local Area Network (LAN) built using Cisco Packet Tracer. The purpose of this lab is to practice basic network configuration, IPv4 addressing, and connectivity testing.

## Objectives

- Build a basic LAN in Cisco Packet Tracer
- Connect end devices to a network switch
- Configure IPv4 addresses
- Verify network connectivity
- Practice basic network troubleshooting

## Network Devices

- 1 Cisco Switch
- 2 PCs
- Ethernet connections

## IP Addressing

| Device | IP Address | Subnet Mask |
|--------|------------|-------------|
| PC0 | 192.168.1.10 | 255.255.255.0 |
| PC1 | 192.168.1.20 | 255.255.255.0 |

## Network Topology

PC0 → Switch → PC1

## Testing

Connectivity between the devices is tested using the `ping` command.

Example:

`ping 192.168.1.20`

A successful ping verifies that the two PCs can communicate across the LAN.
